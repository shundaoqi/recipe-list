# レシピリストアプリ 要件定義 v1.2

## 1. 前提

- 利用者：2 人のみ。ユーザーの区別はしない
- 端末：スマホのブラウザを中心に使う。ホーム画面に追加できる Web アプリ（PWA）
- データ：レシピはクラウドに保存し、どちらかが更新するともう一方にも反映される

## 2. 機能要件

### 2.1 アクセス制限

- ログイン・合言葉などのアクセス制限は持たない
- URL を知っていれば誰でも閲覧・編集できることを許容する（URL は 2 人だけで共有する）

### 2.2 レシピ登録・編集・削除

| 項目          | 必須 | 内容                                                                                 |
| ------------- | ---- | ------------------------------------------------------------------------------------ |
| 料理タイトル  | ○    | 例：鶏むねの甘辛焼き                                                                 |
| TikTok リンク | −    | URL 形式のみチェック。タップで動画を開く                                             |
| カテゴリ      | ○    | 牛／豚／鳥／魚／副菜／その他 のいずれか 1 つ（固定。麺・ご飯ものなどの主食はその他） |
| 材料          | ○    | 1 行ごとに「材料名・数量・単位」。行の追加・削除可                                   |
| メモ          | −    | 自由記述（作り方などを書く）                                                         |

- 単位は選択式：g、ml、個、本、枚、切れ、尾、束、株、玉、片、袋、パック、缶、cm、カップ、大さじ、小さじ、適量、少々
- 数量は「適量」「少々」のとき入力不要
- 材料名は過去の入力から候補を出し、表記ゆれを防ぐ

### 2.3 レシピ一覧と材料一覧

- カテゴリのタブで絞り込む：すべて／牛／豚／鳥／魚／副菜／その他（タブは横スクロール）
- 一覧にはタイトルと材料の一部を表示し、タップで詳細を開く
- 各料理に選択ボタンがあり、選ぶとその料理の材料が材料一覧に追加される。もう一度押すと外れる
- 材料一覧では、同じ材料名・同じ単位のものを合算する
  - 例：鶏もも肉 300g ＋ 250g → 550g
  - 単位が違うものは並べて表示する（例：玉ねぎ 1個 ＋ 100g）
  - 「適量」「少々」は合算せず材料名だけ表示する
- 材料一覧にコピーボタンを付け、テキストとしてクリップボードにコピーできる

  ```
  鶏もも肉 550g
  玉ねぎ 1個 + 100g
  みりん 大さじ3
  揚げ油 適量
  ```

- 「クリア」ボタンで選択をすべて外す
- 選択状態は端末ごとに保持する（2 人の間では共有しない）
- アプリを開き直したときや、別のアプリから戻ってきたときに、最新のレシピと新しいバージョンのアプリを取得する

### 2.4 データの方針

- 基礎調味料（塩・砂糖・醤油・胡椒）と水は家に常にあるものとして、材料に登録しない
  - 表記違い（しょうゆ、濃口醤油、こしょう、黒胡椒、ブラックペッパー、塩こしょう など）も含む
  - 塩昆布・塩麹・柚子胡椒は別の食材なので登録する
- 作り方はメモに書く
- カテゴリの判断基準
  - 牛・豚・鳥・魚：主役の食材で決める。えび・たこ・帆立などの魚介も魚
  - 合挽き肉、種類の書かれていないひき肉は豚
  - 麺・ご飯ものなどの主食（ご飯込みの丼、ビビンバ、うどん、ドリア、おにぎり など）はその他
  - 丼の具だけを作り置きするもの（〜の素、冷凍ストック）は具の肉で決める
  - 汁物と、少量の肉・魚介（ハム、ウインナー、ツナ、ちくわ、明太子 など）を使う野菜料理は副菜

### 2.5 初期データ

2026-11-15 に、LINE「料理！」で共有した TikTok レシピ集（131 件）を一括登録した。

| 牛  | 豚  | 鳥  | 魚  | 副菜 | その他 |
| --- | --- | --- | --- | ---- | ------ |
| 2   | 34  | 30  | 22  | 33   | 10     |

- 材料名から「（タレ）」「【下味】」などの補足を外し、同じレシピ内の同じ材料はまとめた
- 分量は数量＋単位に変換した（例：大さじ1と1/2 → 大さじ1.5、300g×2枚 → 600g）
  - 範囲のある分量（2〜3個）は多い方にした
  - 「お好みで」「たっぷり」などは適量、「ひとつまみ」「少し」などは少々にした
  - 変換で情報が落ちるもの（「1/2袋（100g）」など）は、元の表記をメモの「分量の原文」に残した
- メモには、何人分か・作り方・元データの補足・分量の原文を入れた
- 元データで材料が推測のもの（9 件）は、メモにその旨を書いた

## 3. 対象外

- TikTok からの材料の自動取得
- 人数による分量の換算、同じ料理の回数指定
- 献立の保存・共有、曜日ごとの割り当て、履歴
- 買い物リストのチェック機能
- アプリ上でのカテゴリの追加・変更
- 常備品の除外（基礎調味料と水は登録しない運用で対応）
- オフライン対応
- ログイン、ユーザー管理、招待
