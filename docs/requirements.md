# レシピリストアプリ 要件定義 v1.1

## 1. 前提

- 利用者：2 人のみ。ユーザーの区別はしない
- 端末：スマホのブラウザを中心に使う。ホーム画面に追加できる Web アプリ（PWA）
- データ：レシピはクラウドに保存し、どちらかが更新するともう一方にも反映される

## 2. 機能要件

### 2.1 アクセス制限

- ログイン・合言葉などのアクセス制限は持たない
- URL を知っていれば誰でも閲覧・編集できることを許容する（URL は 2 人だけで共有する）

### 2.2 レシピ登録・編集・削除

| 項目          | 必須 | 内容                                                                                 |
| ------------- | ---- | ------------------------------------------------------------------------------------ |
| 料理タイトル  | ○    | 例：鶏むねの甘辛焼き                                                                 |
| TikTok リンク | −    | URL 形式のみチェック。タップで動画を開く                                             |
| カテゴリ      | ○    | 牛／豚／鳥／魚／副菜／その他 のいずれか 1 つ（固定。麺・ご飯ものなどの主食はその他） |
| 材料          | ○    | 1 行ごとに「材料名・数量・単位」。行の追加・削除可                                   |
| メモ          | −    | 自由記述                                                                             |

- 単位は選択式：g、ml、個、本、枚、切れ、尾、束、株、玉、片、袋、パック、缶、cm、カップ、大さじ、小さじ、適量、少々
- 数量は「適量」「少々」のとき入力不要
- 材料名は過去の入力から候補を出し、表記ゆれを防ぐ

### 2.3 レシピ一覧と材料一覧

- カテゴリのタブで絞り込む：すべて／牛／豚／鳥／魚／副菜／その他（タブは横スクロール）
- 一覧にはタイトルと材料の一部を表示し、タップで詳細を開く
- 各料理に選択ボタンがあり、選ぶとその料理の材料が材料一覧に追加される。もう一度押すと外れる
- 材料一覧では、同じ材料名・同じ単位のものを合算する
  - 例：鶏もも肉 300g ＋ 250g → 550g
  - 単位が違うものは並べて表示する（例：玉ねぎ 1個 ＋ 100g）
  - 「適量」「少々」は合算せず材料名だけ表示する
- 材料一覧にコピーボタンを付け、テキストとしてクリップボードにコピーできる

  ```
  鶏もも肉 550g
  玉ねぎ 1個 + 100g
  醤油 大さじ3
  塩 少々
  ```

- 「クリア」ボタンで選択をすべて外す
- 選択状態は端末ごとに保持する（2 人の間では共有しない）

## 3. 対象外

- TikTok からの材料の自動取得
- 人数による分量の換算、同じ料理の回数指定
- 献立の保存・共有、曜日ごとの割り当て、履歴
- 買い物リストのチェック機能
- カテゴリの追加・変更
- 常備品の除外
- ログイン、ユーザー管理、招待
