# レシピリストアプリ 画面構成 v1.1

要件は [requirements.md](requirements.md) を参照。

## 1. 画面一覧

| ID  | 画面                 | URL                                 | 役割                                           |
| --- | -------------------- | ----------------------------------- | ---------------------------------------------- |
| S1  | レシピ一覧（ホーム） | `/`、`/?c=<カテゴリ>`               | カテゴリで絞り込み、料理を選択する             |
| S2  | 材料一覧             | `/ingredients`                      | 選択した料理の材料を合算して表示し、コピーする |
| S3  | レシピ詳細           | `/recipes/:id`                      | 1 品の材料・リンク・メモを見る                 |
| S4  | レシピ登録・編集     | `/recipes/new`、`/recipes/:id/edit` | 新規登録と既存レシピの編集（同じフォーム）     |

上記以外の URL は S1 を表示する。

## 2. 画面遷移

```
            ┌──────────── 戻る ────────────┐
            ▼                              │
  ┌──────────────────┐  料理名タップ  ┌──────────┐  編集  ┌──────────────┐
  │ S1 レシピ一覧     │──────────────▶│ S3 詳細   │──────▶│ S4 登録・編集 │
  │                  │◀── 削除後 ─────│          │◀─保存─│              │
  └──────────────────┘               └──────────┘       └──────────────┘
     │        ▲   │                                         ▲
     │        │   └────────────── ＋ボタン ──────────────────┘
     │ 下部バー │ 戻る                                (保存後は S1 へ)
     ▼        │
  ┌──────────────────┐
  │ S2 材料一覧       │
  └──────────────────┘
```

- S2・S3 の「戻る」は、最後に開いていた S1（カテゴリのタブを含む）に戻る

## 3. 各画面

### S1 レシピ一覧（ホーム）

```
┌─────────────────────────────┐
│ レシピ                    ＋ │
├─────────────────────────────┤
│ [すべて] 牛 豚 鳥 魚 副菜 …  │  ← 横スクロール
├─────────────────────────────┤
│ ☑ 油淋鶏                  鳥 │
│   鶏もも肉、酒、片栗粉…      │
├─────────────────────────────┤
│ ☐ 鮭のホイル焼き          魚 │
│   鮭、しめじ、バター…        │
├─────────────────────────────┤
│ ☑ ほうれん草の胡麻和え  副菜 │
│   ほうれん草、すりごま…      │
├─────────────────────────────┤
│            ⋮                │
├─────────────────────────────┤
│  材料一覧を見る（2品選択中）▶ │
└─────────────────────────────┘
```

- 左のチェックボックス：選択／解除。材料一覧に追加・削除される
- 行のそれ以外の部分をタップ：S3 詳細へ
- 右上の ＋：S4（新規登録）へ
- 下部バー：S2 へ。選択が 0 品のときは非表示
- タブはカテゴリの絞り込みのみ。絞り込んでも選択状態は保持する。選んだタブは URL（`?c=`）に入る
- 一覧は登録の新しい順
- レシピが 0 件のときは「右上の＋からレシピを登録しましょう」、絞り込み結果が 0 件のときは「このカテゴリのレシピはまだありません」を表示
- 読み込み中は「読み込み中…」、読み込みに失敗したら「再読み込み」ボタンを表示

### S2 材料一覧

```
┌─────────────────────────────┐
│ ← 材料一覧                   │
├─────────────────────────────┤
│ 選択中の料理（2品）          │
│  油淋鶏                  ✕   │
│  ほうれん草の胡麻和え    ✕   │
├─────────────────────────────┤
│ 材料（5件）                  │
│ 鶏もも肉        600g         │
│ 酒              大さじ1      │
│ 片栗粉          適量         │
│ ほうれん草      1束          │
│ すりごま        大さじ2      │
├─────────────────────────────┤
│ [ クリア ]     [ コピー ]    │
└─────────────────────────────┘
```

- 材料の並び順：最初に出てきた順（選択した料理の順、料理内の材料の順）
- ✕：その料理だけ選択を外す
- コピー：材料部分をテキストでコピーし、「コピーしました」を短く表示。失敗したら「コピーできませんでした」
- クリア：確認なしで全選択を外して S1 に戻る
- 選択が 0 品のときは案内文を表示し、クリア・コピーを無効にする

### S3 レシピ詳細

```
┌─────────────────────────────┐
│ ←                  編集  削除 │
├─────────────────────────────┤
│ 鳥                           │
│ 油淋鶏                       │
│ [ TikTokで見る ↗ ]           │
├─────────────────────────────┤
│ 材料                         │
│  鶏もも肉        600g        │
│  酒              大さじ1     │
│  片栗粉          適量        │
├─────────────────────────────┤
│ メモ                         │
│  作り方                      │
│  1. タレ作り：ネギを…        │
├─────────────────────────────┤
│ [ 材料一覧に追加 ]           │
└─────────────────────────────┘
```

- TikTok リンクが未登録ならボタンを出さない。リンクは別タブ（TikTok アプリ）で開く
- メモは改行をそのまま表示する
- 削除：確認ダイアログを出してから削除し、S1 に戻る。失敗したら「削除できませんでした」
- 下部ボタン：選択中なら「材料一覧から外す」に切り替わる
- 存在しない ID のときは「レシピが見つかりません」を表示

### S4 レシピ登録・編集

```
┌─────────────────────────────┐
│ ← レシピ登録          保存   │
├─────────────────────────────┤
│ 料理名 *                     │
│ [                         ]  │
│ カテゴリ *                   │
│ ( 牛 )( 豚 )( 鳥 )           │
│ ( 魚 )( 副菜 )( その他 )     │
│ TikTokリンク                 │
│ [ https://               ]   │
├─────────────────────────────┤
│ 材料 *                       │
│ [鶏むね肉   ][300 ][g   ▼] ✕ │
│ [みりん     ][2   ][大さじ▼]✕│
│ [           ][    ][g   ▼] ✕ │
│ ＋ 材料を追加                │
├─────────────────────────────┤
│ メモ                         │
│ [                         ]  │
│ [                         ]  │
└─────────────────────────────┘
```

- 材料名入力時、登録済みの材料名から候補を出す
- 単位が「適量」「少々」のときは数量欄を無効にする
- 新規登録は空の材料行 3 行、編集は登録済みの材料＋空の 1 行で始まる
- 空の材料行は保存時に無視する
- 保存時のチェック：料理名・カテゴリ・材料 1 行以上が必須。数量が必要な単位は数量が 0 より大きいこと。リンクは URL 形式のみ確認
- 一度保存を押してエラーが出たら、以降は入力のたびにエラー表示を更新する
- 入力途中で ← を押したら「破棄しますか？」を確認
- 保存後：新規は S1、編集は S3 に戻る。失敗したら「保存できませんでした」
